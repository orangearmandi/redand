# RedAnd - Mobile Passive Network Auditor



## Overview

**RedAnd** is an open-source and free mobile application designed to perform **passive network auditing** on Android devices without requiring root privileges.

The application combines modern mobile development technologies with network discovery techniques to identify devices, detect services, analyze communication metadata, and provide a basic security assessment of local networks while respecting Android's security restrictions.

The project was developed as part of a research work focused on mobile cybersecurity and network analysis.

---

## Features

- Passive network monitoring using Android VPNService
- Device discovery on local networks
- Network information collection
- ICMP Ping testing
- TCP Socket connectivity testing
- Multicast DNS (mDNS) service discovery
- SSDP / UPnP device discovery
- Local database support
- Material Design 3 interface
- Native Android integration using Kotlin
- Cross-platform architecture based on Flutter
- Open Source
- Free to use

---

## Architecture

The application follows a modular architecture composed of three primary layers:

```
Flutter UI
      │
      ▼
main.dart
      │
Provider (State Management)
      │
      ▼
VpnController
      │
MethodChannel / FFI
      │
      ▼
Native Kotlin Layer
      │
      ▼
Android VPNService
Android Network APIs
```

This architecture allows Flutter to remain independent from the native implementation while still accessing Android APIs required for passive network analysis.

## Permissions

The application uses Android network permissions including:

- INTERNET
- ACCESS_NETWORK_STATE
- ACCESS_WIFI_STATE
- CHANGE_WIFI_MULTICAST_STATE
- FOREGROUND_SERVICE
- BIND_VPN_SERVICE

The VPN service is used **only** to inspect metadata generated by the local device. The application does **not** capture payload data or perform intrusive network attacks.

## Research Background

This project was developed as part of the research:

> **Mobile Application for Passive Network Auditing Based on Protocol Analysis and Service Detection**

The objective is to demonstrate that passive network auditing can be performed from Android devices without requiring root privileges while maintaining compliance with Android security policies.
